## Dependency

Required:
- Python 3 (version > 3.10)
- venv (Python offically ship with this, but checking is still required)

## Install and Run

Cloning this repository, and move to the newly created directory:

```
git clone https://github.com/gianghia123/ai-intrusion-detection
cd ai-intrusion-detection
```

Run `run.sh` with appropriate permission

```
chmod +x ./run.sh  # Run this if the file is not executable
./run.sh
```
The script will install any dependency in a virtual environment using venv, and prompt you to choose to train all model, or evaluate them.
